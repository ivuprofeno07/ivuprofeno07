# Hola, soy @ivuprofeno07

Estoy desarrollando **Sentinel**, un panel web que reúne noticias, resultados deportivos y repositorios destacados de GitHub.

## Proyecto destacado

[**Sentinel**](https://github.com/ivuprofeno07/hola) permite consultar marcadores y clasificaciones, explorar fichas de clubes y descubrir repositorios con actividad reciente. También cuenta con una edición pública de consulta preparada para actualizarse con GitHub Actions.

**Tecnologías:** TypeScript, React, Node.js, Express y SQLite.
